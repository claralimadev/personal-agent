# /status — Situação atual

Use o runtime-manager (`npm run runtime -- status`) + state.md do projeto atual.

Apresente:
- Projeto e papel (DEV/PO);
- Tarefa em andamento e pendências;
- Branch/estado do git relevante;
- Bloqueio atual (se houver);
- Última evidência registrada;
- Próximo passo sugerido.

Curto e direto. Não carregue história de outros projetos.
