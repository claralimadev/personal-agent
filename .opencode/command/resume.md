# /resume — Retomar trabalho

1. Rode o runtime-manager (`npm run runtime -- start`) para confirmar projeto e localizar o runtime atual.
2. Carregue `state.md` do projeto: qual tarefa estava em andamento, pendências, próximo passo.
3. Compare o estado salvo com a realidade (git status/branch, código) e aponte divergências.
4. Apresente o próximo passo concreto e pergunte se seguimos.

Não recontar decisões que já estão em decisions.md — referencie-as. Se o contexto mudou, registre antes de avançar.
