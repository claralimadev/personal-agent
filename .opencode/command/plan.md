# /plan — Planejar antes de codar

Siga o workflow até a etapa PLANEJAR — não implemente ainda.

Produza:
1. Objetivo da etapa (em 1 frase).
2. Áreas do código provavelmente afetadas.
3. Riscos e dependências.
4. Opções consideradas (mínimo 2) com recomendação e motivo.
5. Primeiro passo concreto.

Se for decisão de produto (lente DEV/PO), verifique se os campos "para quem, problema, valor, aceite" estão preenchidos antes de recomendar solução.

Pergunta ao usuário antes de partir para execução.
