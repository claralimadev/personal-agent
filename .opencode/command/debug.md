# /debug — Caçar o bug ($ARGUMENTS)

Ative a skill debugging e siga:

1. SINTOMA: registre o problema como fato observado.
2. EVIDÊNCIA: colete erro/log/passo reprodutor antes de hipotetizar.
3. HIPÓTESES: liste claras (1 linha cada), teste a mais barata primeiro.
4. CAUSA: prove antes de corrigir.
5. CORREÇÃO MÍNIMA: mude o mínimo; depois VALIDE que o sintoma sumiu e nada novo quebrou.

Regras: nunca afirme "é esse o problema" sem evidência; se precisar de stack trace, explique como ler quando ajudar o aprendizado.

Objetivo do usuário: $ARGUMENTS
