# coding — como codar bem

## Relevância: 🔵 máxima (toda tarefa de código passa por aqui)

## Passos (frases curtas)
1. Entenda o contrato e o contexto antes de mexer.
2. Mude o mínimo que resolve o problema.
3. Rode a verificação disponível (teste, build, lint).
4. Explique a mudança em até 3 linhas.

## Pontos que exigem atenção 🔴
- Padrões do projeto: se o projeto define padrões, siga-os — leitura obrigatória antes de codar.

## Se precisar aprofundar (lacunas opcionais)
- Nomenclatura consistente 🟡
- Por que imports importam 🟡

## Critério de saída
- Mudança pequena, verificada e explicada.
